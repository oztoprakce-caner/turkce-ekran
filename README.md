# Турецкий экран

Тренажёр турецкого языка для русскоговорящих. Интерфейс, вопросы и ответы — на русском, речь — на турецком.

- **Сцены:** 68 анимированных сцен в 8 темах (знакомство, кафе, рынок, транспорт, отель, аптека, работа, дом). Озвучка — турецкий голос браузера.
- **Видео:** 175 коротких фрагментов с настоящей турецкой речью:
  - сериалы «Эзель», «Чёрная любовь» (Kara Sevda), «Европейская сторона» (Avrupa Yakası), «Фатмагюль» (Fatmagül’ün Suçu Ne?), «Кузей Гюней» (Kuzey Güney), «Листопад» (Yaprak Dökümü), комедии «Восьмидесятые» (Seksenler), «Лейла и Меджнун» (Leyla ile Mecnun), «Кавак Еллери» (Kavak Yelleri) — с официальных каналов;
  - ролики [Easy Turkish](https://www.youtube.com/@EasyTurkish) (погода, завтрак, где мой телефон, дом мечты, детство).
  Видео встраиваются через YouTube; все права принадлежат их владельцам.
- **Смешанный режим:** в обычном раунде из 10 заданий примерно 4 — видео, остальные — сцены. Кнопка «Видео-режим» даёт только видео.
- **Уровни A1–B2:** у каждой фразы есть уровень; можно тренировать только нужный.
- **C1 — видео автора курса:** только видео, которые добавляет владелец; хранятся в его Google Диске и показываются только при выборе уровня C1.
- Прогресс (очки, точность, ошибки) хранится в браузере.
- **Рейтинг игроков:** игрок один раз вводит имя (без регистрации); после каждого раунда его очки отправляются в Google Таблицу владельца и видны всем на экране «Рейтинг» (за неделю и за всё время). Сервер — `leaderboard.gs` (Google Apps Script).

Сайт: https://oztoprakce-caner.github.io/turkce-ekran/
