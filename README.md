# Турецкий экран

Тренажёр турецкого языка для русскоговорящих. Интерфейс, вопросы и ответы — на русском, речь — на турецком.

- **Сцены:** 68 анимированных сцен в 8 темах (знакомство, кафе, рынок, транспорт, отель, аптека, работа, дом). Озвучка — турецкий голос браузера.
- **Видео:** 66 коротких фрагментов с настоящей турецкой речью:
  - сериалы «Эзель», «Чёрная любовь» (Kara Sevda), «Европейская сторона» (Avrupa Yakası) — с официальных каналов;
  - ролики [Easy Turkish](https://www.youtube.com/@EasyTurkish) (погода, завтрак, где мой телефон, дом мечты, детство).
  Видео встраиваются через YouTube; все права принадлежат их владельцам.
- **Смешанный режим:** в обычном раунде из 10 заданий примерно 4 — видео, остальные — сцены. Кнопка «Видео-режим» даёт только видео.
- **Уровни A1–B2:** у каждой фразы есть уровень; можно тренировать только нужный.
- Прогресс (очки, точность, ошибки) хранится в браузере.

Сайт: https://oztoprakce-caner.github.io/turkce-ekran/
